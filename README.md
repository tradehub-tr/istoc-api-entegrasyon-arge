# iStoc API Entegrasyon Ar-Ge Belgesi

iStoc'un dış uygulamalara API ile bağlanması için hazırlanan araştırma belgesi. 111 kalemlik kapsam listesinin gap analizi, mevcut altyapı envanteri ve kümeler altında geliştiricinin uygulayacağı yol haritası tek HTML sayfada toplanmıştır.

Sürüm 1.1 (6 Kasım 2026): 14 ürün/iş kararı işlendi; yol haritası 41 görev (32 olmazsa olmaz, 9 ikinci dalga).

Bu bir görev oluşturma belgesidir; API geliştirmesi içermez. Kamuya açık sürümde bir güvenlik bulgusunun teknik ayrıntısı bilinçli olarak maskelenmiştir.
